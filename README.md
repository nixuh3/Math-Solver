# Math Solver

## Requirements

- CMake ≥ 3.16
- C++20
- A compatible compiler (GCC, Clang, MSVC)

## Build Instructions

1. Clone the repository

```bash
git clone https://github.com/nixuh3/Math-Solver.git
cd Math-Solver
```

2. Configure project

```bash
cmake -S . -B build
```

3. Build

```bash
cmake --build build
```

4. Run

```bash
./build/Math-Solver
```
